    <h2>Smart Wave Energy Conversion via Learning and Low-Cost Control</h2>
    <p>SWELL develops data-driven model predictive control for wave energy converters, with the goal of improving real-time performance while keeping sensing and actuation requirements practical.</p>
    <p>The project combines nonlinear hydrodynamic modeling, efficient MPC design, experimental validation, and open-source software to help make wave energy more competitive.</p>
